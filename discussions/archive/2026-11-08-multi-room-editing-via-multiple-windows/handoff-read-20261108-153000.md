## Decided (by the User)
- One server process serves several rooms, one per folder; each room in its own window.
- "Quit room" (ends that room) and "Shutdown server" (ends all rooms) are separate actions.
- Quit room stops that room's agents and worker programs, including their child commands.
- Restart and Shutdown list busy rooms and ask for confirmation, on every route (buttons, typed
  /restart and /shutdown, the Dock app's Quit via a Cancel / Shutdown dialog).
- Only the launch room replicates with charon; other rooms' Peers panel says why.
- A second room in the same Git repository gets no worker, with the reason shown.
- Pages on any device count as "open" (provisional).
